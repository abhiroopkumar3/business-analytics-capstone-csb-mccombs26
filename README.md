# Columbus State Bank – Capstone Project Repository

This repository contains all deliverables, data assets, and analytical work developed as part of the MS Business Analytics Capstone project at Texas McCombs School of Business, The University of Texas at Austin. The project evaluates the feasibility of a digital livestock auction settlement platform for Columbus State Bank, focusing on market sizing, financial viability, and operational impact.

### Core Deliverables

* **Capstone Presentation Slide Deck - Columbus State Bank.pdf**
  Final presentation summarizing problem, analysis, and recommendations.

* **Capstone Poster - Columbus State Bank.pdf**
  Visual summary of the project for academic showcase.

* **CSB_Stage3_Market_Sizing.docx**
  Detailed documentation of TAM, SAM, and SOM analysis.

* **CSB_TAM_SAM_SOM.xlsx**
  Market sizing model with assumptions and calculations.

## Key Highlights

* Built a **data-driven market sizing model** (TAM ~ $5.9B) to evaluate opportunity scale
* Developed **financial and adoption scenarios** to estimate revenue potential
* Identified **operational inefficiencies** in current livestock settlement workflows
* Delivered a **Nuanced “Build” recommendation** with phased rollout strategy
* Created an **interactive dashboard** for stakeholder decision-making
